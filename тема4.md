# Огляд та характеристики слотів розширення (expantion slots) на материнській платі

### Слоти розширення потрібні для додаткових пристроїв, які можна підключити до материнської плати, і які матимуть порти на задній панелі комп'ютера

### У наш час основним стандартом є PCI Express (Peripheral Component Interconnect Express) або ще називають PCIe
![PCI](https://upload.wikimedia.org/wikipedia/commons/3/3e/PCI-E_%26_PCI_slots_on_DFI_LanParty_nF4_SLI-DR_20050531.jpg)
* **Послідовна передача даних:** можна виділити те що на відміну від своїх попередників передача данних відбувається пакетами а не паралельно
* **Лінії (Lanes):** Кожен слот має певну кількість ліній передачі. Позначаються як x1, x4, x8, x16.
* **Версії:** Кожне покоління (3.0, 4.0, 5.0) подвоює швидкість кожної лінії.

| Тип слота | К-ть контактів | Призначення |
| :--- | :--- | :--- |
| **PCIe x1** | 36 | Периферія (Звук, Wi-Fi) |
| **PCIe x4** | 64 | Накопичувачі (SSD) |
| **PCIe x8** | 98 | RAID-контролери, Серверні карти |
| **PCIe x16** | 164 | Відеокарти |

![PCI](https://cdn.shopify.com/s/files/1/0738/1499/9346/files/PCIe-slots-of-different-lengths-and-types_480x480.png?v=1731391381)


## Карти розширення (expantion cards) на інтерфейсі PCI-e 

1. **Відеокарта (GPU):** Найпотужніший пристрій, використовує **PCIe x16** для максимальної пропускної здатності.
![PCI](https://www.hellotech.com/blog/wp-content/uploads/2020/02/Gaming-GeForce.jpg)

2. **Звукова карта:** Використовується аудіофілами або професіоналами. Зазвичай це **PCIe x1**.

![PCI](https://content2.rozetka.com.ua/goods/images/big/405502458.jpg)

3. **Мережева карта 10 Gbps:** Для надшвидкого інтернету або локальних мереж. Потребує **PCIe x4** або **x8**.

![PCI](https://dimiks.ua/images/network-cards/nic-10g-4x-sfpplus-intel-xl710/nic-intel-4sfpplus-xl710-03.jpg)

4. **Адаптер M.2 NVMe:** Дозволяє додати швидкий SSD, якщо штатні місця на платі закінчилися. Використовує **PCIe x4**.

![PCI](https://images.prom.ua/3470581131_w1280_h640_3470581131.jpg)

5. **Wi-Fi + Bluetooth адаптер:** Для бездротового зв'язку. Найчастіше формат **PCIe x1**.

![PCI](https://images.prom.ua/4081661983_w1280_h640_4081661983.jpg)

6. **Контролер USB 3.2:** Додає порти USB-C або додаткові USB-A. Слот **PCIe x1** або **x4**.

![PCI](https://dreamtech.ua/image/cache/catalog/image/cache/catalog/sonnet/images/images500x500/1542016209_1442232-500x500.webp)

7. **RAID-контролер:** Для керування масивами жорстких дисків у серверах. Використовує **PCIe x8**.

![PCI](https://advdownload.advantech.com/productfile/PIS/e0f5c606-caa7-4893-9e4d-17bb44f4acb2/Category_Photo/RAID-Controller-Category20231018111954.png)

8. **Плата захоплення відео (Capture Card):** Для стрімінгу ігор з консолей. Формат **PCIe x1** або **x4**.
![PCI](https://content.rozetka.com.ua/goods/images/big/398808758.jpg)
